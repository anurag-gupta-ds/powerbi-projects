# 🤖 AI ROI & Workflow Automation Dashboard

Interactive Power BI dashboard analyzing AI investment, workflow automation, and business impact through dynamic visualizations and executive-level KPIs.

---

## 📌 Objective
Analyze AI adoption across industries to evaluate investment, ROI, annual savings, revenue impact, employee satisfaction, and workflow automation performance.

---

## 🛠️ Tools Used
- Power BI Desktop
- Power Query (ETL)
- DAX Formulas

---

## 📊 Dashboard Features
- Executive KPI Cards
- AI Investment Analysis
- Annual Savings Tracking
- Revenue Impact Analysis
- Average ROI by Department
- AI Tool Adoption Distribution
- Country-wise Revenue Impact Map
- Industry-wise Investment Analysis
- Yearly Investment vs Savings Trend
- Company Details Table
- Interactive Slicers (Country, AI Tool, Industry, Department, Year)
