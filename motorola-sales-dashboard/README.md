# 📱 Motorola Sales Dashboard

Interactive Power BI dashboard analyzing Motorola product sales performance built under guidance of Satish Dhawale's Power BI course.

---

## 📌 Objective
Analyze Motorola sales data to track performance, identify trends, and generate business insights.

---

## 🛠️ Tools Used
- Power BI Desktop
- Power Query (ETL)
- DAX Formulas

---

## 📊 Dashboard Features
- Sales KPI Cards
- Product wise performance
- Region wise analysis
- Interactive Slicers
- Time based trends
